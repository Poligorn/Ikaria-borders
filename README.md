# Ikaria Borders

Серверный и клиентский мод для сервера MC-Ikaria (Minecraft 1.21.1, NeoForge).

Что будет уметь мод:

- рисовать границы зон на World Map и миникарте Xaero, без приватов OPAC;
- запрещать приваты OPAC в диких землях (там разрешены только серверные приваты);
- задавать правила зон: PvP, урон, спавн мобов;
- описывать зоны любой формы в конфиге: круг, квадрат, многоугольник, кольцо. Конфиг перезагружается без рестарта.

Сейчас готово только техническое задание: [docs/TZ_ikaria_borders_v2.md](docs/TZ_ikaria_borders_v2.md). Код появится после его согласования.

Mod id: `ikaria_borders`.
